FILM!

Итоговое выполнение проектной работы по спринтам 16, 17 и 18 курса "Full-Stack разработчик" от Яндекс Практикума.

Описание проекта

Проект представляет собой онлайн-сервис по бронированию билетов в кинотеатр. На сайте пользователь может посмотреть список фильмов, перейти в карточку конкретного фильма и ознакомиться с его детальным описанием, посмотреть предлагаемые расписания по каждому фильму и создать заказ по бронированию одного или нескольких мест после ввода необходимых данных.

Задачи 

При выполнении проектной работы, были реализованы следующие задачи:

1) Созданы контроллеры и сервисы обработки запросов клиентской части (получение информации о фильмах, бронирование билетов).
2) Создан репозиторий на базе БД Postgres.
3) Настроен TypeORM для взаимодействия с Postgres.
4) Реализован модуль чтения настроек из переменных среды.
5) Созданы логгеры DevLogger, JsonLogger и TSKVLogger.
6) Написаны тесты для проверки работы логгеров и контролеров приложения (запуск из backend/ команда npm run test).
7) Приложение докеризировано, создан Github Action, который при обновлении собирает образы Docker для backend и frontend и публикует их в GitHub Registry.
8) Настроен удаленный сервер, прикреплено доменное имя https://dmitriykhristich.nomorepartiesco.ru/, выполнен деплой проекта.
9) Выпущен сертификат, настроено подключение к сайту по https и редирект с http на https.

Установка локально с Docker

В директориях:

backend/ Создайте .env файл из примера .env.example

frontend/ Создайте .env файл из примера .env.example

Запустите команду: sudo docker-compose -f docker-compose.local.yml up -d

Через PGAdmin (http://localhost:8080/) авторизуйтесь, используя email, password из .env. Создайте сервер, базу данных и таблицы. Для создания базы данных и таблиц используйте скрипты из папки test внутри backend.

Приложение будет доступно по адресу http://localhost:8081/
